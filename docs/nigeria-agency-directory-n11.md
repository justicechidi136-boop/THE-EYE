# Nigeria agency directory N11 operational enrichment

## Scope and decision

N11 responds to the N10 evidence without changing `agency-recommendation-v1`.
N10 found no wrong-capability or wrong-jurisdiction reviews; its dominant finding
was missing verified operational data. N11 therefore promotes only records that
have official endpoint evidence and leaves unverified candidates in the backlog.

## Promoted endpoint

`NG-FCT-FIRE` gains one verified-address operational office at Plot 1, Kapital
Street, Area 11, Garki. The official FCTA Fire Service page publishes the
address, and the official FCTA FAQ publishes `112` and the Fire emergency call
centre numbers. N11 imports the minimum useful contact set: `112`, one explicit
Fire emergency number, and the official service page.

Potential N10 impact: the FCT Fire fixture and any FCT emergency scenario whose
existing capability mapping legitimately includes Fire response. This is
traceability only; the unchanged recommendation engine determines actual impact.

No coordinate is imported. The official sources do not publish coordinates and
no approved geocoder evidence was supplied. Coordinate evidence therefore
remains `UNKNOWN`, rather than being inferred from Garki, Abuja, the FCT, or a
third-party map.

## Investigated but not promoted

- **PoliceStation:** the repository contains the model and application paths but
  no authoritative station reference dataset/importer. The only existing row is
  a staging test fixture. N11 does not convert stations into `AgencyOffice` and
  does not fabricate the exact coordinates required by the current model.
- **Lagos:** official State pages confirm LASEMA, Fire, LASAMBUS, LASTMA and
  emergency numbers. They do not provide sufficient exact operational addresses
  for the candidate response points. Locality-only LASAMBUS names are retained as
  research leads, not imported endpoints.
- **FRSC:** official command pages confirm command names and publish public
  contact lists, but the reviewed material does not establish exact operational
  command addresses. Driver licence centres are not treated as response bases.
- **Kano SEMA, Enugu Fire and Borno SEMA:** official budgets establish the
  organizations, not verified public operational endpoints or emergency contacts.
- **Third-party maps/directories:** useful only for candidate discovery and not
  accepted as authoritative import evidence.

## Repeatable before/after QA

The N10 fixture set and `agency-recommendation-v1` remain unchanged. By default,
the runner keeps using `[N10 v1]` persisted reviews. For post-enrichment evidence,
set `N10_REVIEW_COHORT=n11-after`; this creates an independent review cohort over
the exact same 47 fixture incidents, avoiding contamination from the baseline.
The cohort option does not alter fixtures, routing, scoring, or outcomes.

Automatic dispatch and escalation remain disabled. The import and QA runner do
not send SMS, email, WhatsApp, push, webhooks, agency API calls, or outbound jobs.

The coverage-cell aggregate is intentionally conservative and did not change;
the scenario-level N10 evidence nevertheless shows that the new FCT Fire office
is a legitimate actionable endpoint for FCT Fire and Flood fixtures. This added
two accepted primary recommendations without changing ranking rules.

The final after-enrichment timing run measured 22.52 ms average, 19.42 ms p50,
46.01 ms p95, and 69.26 ms maximum. The immediately preceding first after run
measured 17.71 ms average, 16.74 ms p50, 23.34 ms p95, and 40.96 ms maximum.
The sample does not indicate an obvious query degradation, but it is too small
to support a production performance claim.

Coordinate provenance after N11 is: authoritative 0, verified-address geocode
0, third-party reference 0, and unknown 142. The increase in unknown coordinates
is expected because the verified FCT address was imported without inventing a
coordinate.
