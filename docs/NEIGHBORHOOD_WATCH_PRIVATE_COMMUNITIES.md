# Neighborhood Watch — Private Communities

Private communities (estates, campuses, associations) require explicit membership.

- Created/approved by authorized THE EYE community administration.
- Join → Pending → Community Admin Approve/Reject.
- Roles are community-scoped (Resident, Volunteer, Patrol lead, Community Admin, etc.) and are not platform admin roles.
- Geofence entry alone never grants private feed or alerts.
