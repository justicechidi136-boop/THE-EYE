# Missing Person Broadcast Policy

## Required fields

- Full name
- Recent photograph (via metadata attachments when provided)
- Age or approximate age
- Gender where appropriate
- Last seen date/time
- Last seen location
- Country
- State/LGA where available
- Clothing description
- Physical description
- Contact or safe response method
- Additional description
- Police report reference where available
- Relationship of reporter to missing person
- Consent/legal declaration
- `clientBroadcastId` for idempotency

## Publication

Missing person broadcasts become **Active** immediately after server validation. No admin approval is required before publication.

## Safeguarding

- Apply special rules for children
- Protect reporter contact details using in-app response where possible
- Include reporting and abuse controls
- Preserve audit history after removal

## Resolution

Authors may mark a missing person as found. Administrators may mark resolved and add official updates.
