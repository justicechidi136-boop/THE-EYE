# Nigeria Agency Directory N4

Status: NATIONAL DIRECTORY COVERAGE EXPANDED

This milestone does not claim that Nigeria's public-safety agency directory is complete. A `NOT_VERIFIED` cell means THE EYE lacks sufficiently verified directory evidence for that category; it does not mean the service does not exist.

## Verification semantics

- `VERIFIED`: at least one appropriately verified directory record supports the category in the jurisdiction.
- `PARTIAL`: relevant evidence exists, but the matching record is only partially verified.
- `NOT_VERIFIED`: THE EYE currently has no sufficiently verified directory record for the category. The service may still exist.
- `UNKNOWN`: a matching record exists, but available evidence is insufficient to classify it as verified or partial.
- `NOT_APPLICABLE`: the category is affirmatively confirmed not to apply. Absence alone never produces this status.
