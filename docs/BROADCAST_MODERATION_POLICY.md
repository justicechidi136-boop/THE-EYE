# Broadcast Moderation Policy

## Administrator responsibilities

Administrators must be able to:

- View broadcasts in their jurisdiction
- Filter by country, state, category, status, author, and date
- Comment with official updates
- Verify broadcasts where evidence supports verification
- Suspend abusive or fraudulent broadcasts
- Restore suspended broadcasts
- Soft-delete broadcasts while preserving audit history
- Mark broadcasts resolved
- Create admin broadcasts within authorised jurisdiction

## Permissions

| Role | Scope |
| --- | --- |
| Super Admin | Global |
| Country Admin | Assigned country |
| State Admin | Assigned state unless country-wide permission granted |
| LGA Admin | Assigned LGA |
| Moderator | Review, comment, report handling |
| Read-only / Auditor | View only |

## Citizen safeguards

- Citizen broadcasts are not labelled **Verified by Admin** unless an authorised admin verifies them.
- Users may report broadcasts and comments.
- High-risk content may be flagged for admin review without delaying initial publication unless law or safety policy requires delay.
- Duplicate detection warns authors but does not block urgent legitimate broadcasts solely on imperfect matches.

## Removal

Admin deletion is soft by default. Audit history is preserved unless legal policy requires hard deletion.

## Comments

Admins may pin official updates, hide abusive comments, and lock comments. Moderation actions are audited.
